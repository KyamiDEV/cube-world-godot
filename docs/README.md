# `docs/`

Durable knowledge. `CLAUDE.md` is policy — what must be true. These files are the
record: what was decided, why, and what is still unknown.

## Decisions

[`adr/`](adr/) — architecture decision records. An ADR captures a choice that is
expensive to reverse, the alternatives rejected and why, the costs accepted, and a
`Revisit if` clause naming the measurement that would reopen it. Accepted records are
superseded, never edited.

## Reverse-engineering notes

[`reference/`](reference/) — what was learned from the reference material and **how much
of it is trusted**. Nothing there is ground truth: it is decompiler output, so every
behavioural claim carries a `HIGH` / `MEDIUM` / `LOW` confidence level.

## Adding a document

- A **contract** goes here as its own file and names its implementation.
- A **decision** goes in `adr/` with the next sequential number.
- A **finding about the reference** goes in `reference/`, with confidence levels.
- Anything that would go stale in a week — session state, task lists — belongs in
  `nextsteps.md`, not here.
